# حاسبة التقسيط الذكية

تطبيق ويب تقدّمي (PWA) عربي لحساب وتتبع خطط التقسيط بالريال العُماني. يعمل على أندرويد وويندوز والأجهزة اللوحية، ويُثبَّت كتطبيق، ويعمل بدون إنترنت بعد أول فتح. لا تسجيل دخول ولا خوادم: البيانات محفوظة على الجهاز (IndexedDB).

Prepared by: Hani Al Ghatrifi

## التقنيات

React 18 + TypeScript + Vite + Tailwind CSS 4 + Dexie (IndexedDB) + vite-plugin-pwa (Workbox) + Vitest. خط Cairo مضمَّن محلياً (يعمل بدون إنترنت). رمز الريال العُماني مأخوذ من ملف الرمز الرسمي ويُرسم بلون النص.

## هيكل المشروع

```
src/lib/money.ts     تحويل وتنسيق المبالغ (بالبيسة كأعداد صحيحة)
src/lib/dates.ts     التواريخ الشهرية وعدّ الأشهر شاملاً
src/lib/engine.ts    محرك الحساب: الإنشاء، القسط الثابت، المرن، المخصص، الدفعات، إعادة الحساب، الملخص، فحص الثوابت
src/lib/backup.ts    النسخ الاحتياطي والتحقق من الملفات
src/lib/csv.ts       تصدير CSV
src/lib/db.ts        التخزين المحلي (Dexie)
src/screens/*        الشاشات السبع
tests/*.test.ts      اختبارات الوحدة (Vitest)
e2e/e2e.py           اختبار شامل في المتصفح (Playwright) يشمل العمل بدون إنترنت
```

## النشر على Vercel

1. ارفع المجلد إلى مستودع GitHub.
2. في Vercel: Add New → Project → اختر المستودع.
3. الإعدادات تُقرأ تلقائياً من `vercel.json` (Build: `npm run build`، Output: `dist`).
4. كل دفع إلى `main` يُنشر تلقائياً.

## التثبيت على أندرويد

1. افتح رابط التطبيق في Chrome.
2. القائمة ⋮ ← «تثبيت التطبيق».
3. افتحه مرة واحدة وأنت متصل؛ بعدها يعمل بدون إنترنت.

## قواعد الحساب

- كل المبالغ تُخزَّن بالبيسة (1 ر.ع. = 1000 بيسة) كأعداد صحيحة؛ لا أخطاء فاصلة عائمة.
- العرض بثلاث منازل افتراضياً (أو منزلتين من الإعدادات؛ عندها تُقرَّب الأقساط المحسوبة إلى 10 بيسات).
- القسط الأخير يسوّي أي فرق تقريب، ولا يتجاوز الرصيد أبداً.
- الرصيد المتبقي = المبلغ − الدفعات الفعلية المسجّلة فقط. القسط المخطط لا يُعدّ مدفوعاً حتى تُسجَّل دفعته.
- إعادة الحساب تمس الأقساط المفتوحة فقط؛ الدفعات والأقساط المدفوعة لا تتغير.
- لا فوائد ولا رسوم.

## تقرير الاختبار

**اختبارات الوحدة (38 ناجحة):** التقسيط المتساوي، القسط الثابت (مثال 1000 / 150 = 6 × 150 + 100 خلال 7 أشهر)، القسط ≥ الرصيد، رفض القسط صفر/سالب، الدفعة الأولى وتاريخ بدء مستقل، تغيير القسط الثابت والمبلغ، عدّ الأشهر شاملاً وتثبيت يوم الاستحقاق في الأشهر القصيرة، تعديل قسط سابق وإعادة توزيع اللاحق (بالتساوي أو بقسط ثابت)، الدفعات الجزئية (مفتوحة أو مع ترحيل الفرق)، الدفع الزائد، الدفعة الإضافية (تقصير المدة أو تخفيض الأقساط)، السداد المبكر وإلغاء الأقساط غير اللازمة، التخطي والتأجيل والحذف والإضافة، حذف دفعة، استعادة الجدول وإعادة التعيين، دقة البيسة، النسخ الاحتياطي والاستعادة (JSON + IndexedDB)، تصدير CSV، وجلسة عشوائية من 60 عملية تتحقق من الثوابت المالية بعد كل خطوة.

**الاختبار الشامل في المتصفح (هاتف 390px وسطح مكتب 1280px):** إنشاء خطة، التحقق من الجدول، تغيير القسط الثابت، تسجيل دفعة كاملة وجزئية، أرقام لوحة التحكم، تصدير CSV، تعديل قسط، الحفظ بعد إعادة التحميل، **فتح التطبيق وإنشاء خطة بدون إنترنت** عبر Service Worker، والوضع الداكن. بدون أخطاء في وحدة التحكم.

**قيود معروفة:**
- البيانات خاصة بكل متصفح/جهاز؛ النقل بين الأجهزة عبر ملف النسخة الاحتياطية.
- PDF يتم عبر نافذة الطباعة («حفظ بصيغة PDF»).
- شكل حقل التاريخ يتبع لغة المتصفح.
- iOS: التثبيت من Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية»؛ لم يُختبر على جهاز iPhone فعلي.
